# 多平台订单 / 物流覆盖

OrderHub 0.3 不再只覆盖京东。每个平台按「能拿到真实数据的方式」标注，没接入的不会假装有数据。

「个人信息副本」优先：订单号、商品、金额、下单时间、运单号最全，文件本身就能确定平台。
账单只适合补漏：支付宝/微信账单通常只写商户名和商品，无法 100% 判断是淘宝还是闲鱼，会落到「其他」或按商户关键词猜。

## 导入入口

PWA → 更多 → 导入订单，支持：

- 支付宝交易流水：ZIP / CSV（GBK 自动识别）
- 微信支付账单：CSV（UTF-8 BOM，自动跳过表头前的说明）
- 平台个人信息副本：CSV / XLSX / JSON / ZIP
- 单文件上限 6MB（前端限制）；上传走 `POST /api/import/file`，body 上限仍是 `ORDERHUB_MAX_BODY`（默认 8MB）

重复导入按 `(platform, platform_order_id)` 去重，第二次是更新不是新增。

### 支付宝

支付宝 App → 我的 → 账单 → 右上角 … → 开具交易流水证明 → 用于个人对账 → 选时间范围 → 邮件收到 ZIP。

### 微信

微信 → 我 → 服务 → 钱包 → 账单 → 常见问题 → 下载账单 → 用于个人对账 → 邮件收到 CSV。

### 平台个人信息副本

各 App 菜单会变，按 App 内「设置 → 隐私 → 个人信息副本 / 数据导出」找；导出通常 24 小时内发到邮箱。仓库里的 `app/platforms.py` 维护每个平台的提示文案，改一处 UI 同步。

## 物流查询

- 订单/导出里的运单号会自动建包裹。
- 短信里的运单号、取件码、驿站也会进包裹看板。
- 快递100 付费 API 没配置时，走公开 Web 查询（免 key）：`app/services/kuaidi_web.py`。
  - 按单号前缀猜承运商；纯数字单号依次试中通/圆通/韵达/申通。
  - 600 秒缓存、全局调用间隔 ≥2s、失败不阻塞。
  - 公开接口限流明显，只做**手动补单**；默认不自动轮询（`ORDERHUB_FREE_TRACKING_POLL=1` 才开）。
  - 会丢弃「最新轨迹比订单创建早 30 天以上」的结果，防止单号复用写错包裹。
  - 非官方接口，可能限流或失效；付费 `KUAIDI100_CUSTOMER/KEY` 配好后优先走付费接口并恢复每 30 分钟自动轮询。
- 手动补：更多 → 补物流，输入运单号立即查一次。

## 浏览器采集（Windows agent）

Windows 上的 `app.collector_agent` 除了京东，还能采集淘宝、拼多多、抖音、闲鱼、转转。按 [WINDOWS-COLLECT.md](WINDOWS-COLLECT.md) 的三步跑：升级 agent → 登录三平台 → 点采集。

1. 在这台 Windows 的 Chrome 9333 里登录对应平台（验证码/滑块要人工过）。
2. PWA → 更多 → 平台覆盖 → 点该平台「采集」；或命令行：
   ```bat
   .venv\Scripts\python -m app.collector_agent --platform taobao
   ```
3. 采集器打开订单页，先嗅探页面自己加载的 JSON，再退回页面文本解析；只写解析到订单号的行。

实测（2026-11-11，未登录状态）：淘宝 → `login.taobao.com`、拼多多 → `/login.html`、闲鱼 → `passport.goofish.com`，三者都能正确识别为「需要登录」。抖音、转转没有稳定的公开网页订单入口：抖音首页只有「我的」，转转 PC 首页只有下载 App；这两个平台默认从首页尝试点「商城/我的订单」，失败会报 `invalid_page`。

抖音/转转如果找不到订单页，用登录后 Chrome 里复制到的真实地址覆盖：

```ini
ORDERHUB_URL_DOUYIN=https://...
ORDERHUB_URL_ZHUANZHUAN=https://...
```

采集器状态会写进「采集记录」：`ok / empty / login_required / captcha / invalid_page / error`。`login_required` 或 `captcha` 时，agent 会把 Chrome 切成可见窗口并打开登录页；登录后点重试，或等它 5 分钟后自动重试。

风险：平台可能弹验证码、限流或改版；不做任何绕过，失败就停下来等人工。所有抓取都在你自己的 Chrome 里，服务端不保存平台 cookie。

## 明确没做

- 免登录抓取：这些平台订单页必须登录，采集器只使用你自己 Chrome 的登录态，不做绕过。
- 抖音/转转的网页订单页长期不稳定；没有可用 URL 时只能走个人信息副本/账单导入。
- 自动读取 iPhone 短信：需要 iOS 快捷指令把短信 POST 到 `/api/sms`（或批量粘贴），仓库不申请短信权限。
- 账单自动定时拉取：支付宝/微信都不提供个人账单 API，只能人工下载后导入。
- 平台登录态 / cookie：OrderHub 不保存任何平台 cookie。

## 回滚

- 代码：`git revert` 对应提交，或服务器 `/opt/orderhub` 切回上一个 tag。
- 数据库：升级前用 `sqlite3 .backup` 备份；`source` 列只增不改旧字段，回滚代码后旧版本仍可读。
- 导入的订单：`DELETE FROM orders WHERE source IN ('alipay','wechat','export')`（先备份）。
